# LMS Query Chatbot

A simple Python chatbot for handling common LMS (Learning Management System) queries.

Features:
- Course and enrollment help
- Assignment and submission guidance
- Exam and deadline information
- Grade and result queries
- Fees and payment help
- General support responses

## Run locally

```bash
python app.py
```

## Example queries

- I need help with my course enrollment.
- When is my assignment due?
- How can I check my grades?
- I need support with my LMS login.
- What are the exam dates?
- I have a payment issue.

Type `exit` to quit the chatbot.
